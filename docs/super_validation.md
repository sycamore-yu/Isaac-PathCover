## 1. 实现与算法正确性

### 已实现的单一运行路径

| 模块 | 实际实现 |
|---|---|
| 地图 | ROG-Map 概率更新、占据与膨胀计数、射线、滑动、查询；可选 ESDF 与 frontier |
| 搜索与引导 | 原 A*、占据起点逃逸、距离视野、旧路径复用、带时间戳的轨迹引导 |
| 走廊 | 原 CorridorGenerator 分段、重叠、点种子修补、简化及局部目标；RISP 生成几何 |
| 位置优化 | MINCO_S4NU、ExpTrajOpt、BackupTrajOpt、解析梯度、时间与顶点参数化、热启动 |
| 航向与求解 | YawTrajOpt 的 3/5/7 次插值；原 cautious L-BFGS、Lewis–Overton 线搜索和停止规则 |
| 执行 | PlanFromRest、ReplanOnce、ExpTraj、BackupTraj、CmdTraj、前缀拼接与原 FSM |
| Newton | 独立 CPU 规划进程；持续推进的物理和控制循环；原电机、分配器、控制器及场景 |

旧 NanoVox、JPS/DMP、GCOPTER 规划器和同步执行入口已删除。
保留的通用 MINCO 插值代码来自已验证的公共数学实现，不构成另一套规划器。
算法与源码对应见 [地图与走廊](super_mapping.md)、[轨迹](super_trajectory.md)和[执行](super_execution.md)。

### 差异边界

唯一几何算法替换为 CIRI → RISP。原版点 RISP 通过官方取样序列对照。
为满足 SUPER 接口，线段种子使用障碍点在线段上的最近投影。
机器人半径在分离平面构造和候选障碍剔除时进入计算。
线段退化为点且半径为 0 时，直接退化为原版点 RISP。
线段与半径扩展不能表述为 PathCover 官方点算法的逐值复刻。

Python 使用 NumPy、SciPy 和 Numba CPU 编译。
数值核禁用浮点快速重排。运行时不调用离线 C++ 对照程序或 ROS。
线性规划、顶点枚举和通用插值使用现有数值库。
退化几何的中心、顶点顺序及非凸优化终点可能出现数值差异。
运行时采用 NumPy 随机生成器；相同整数种子不保证与 C `rand()` 生成相同走廊。

Newton 适配了地图范围、质量、重力和消息接口。
场景资产、动力学、电机和控制器增益保持原配置。
仅供原日志使用的重复 Backup 优化已移除，其第二次输出不进入执行。
原源码中未读取的配置和 CIRI 专用配置已删除。

地图和轨迹驱动直接编译固定提交的原源码。
FSM 驱动提取原方法体，并预设规划返回值。
没有将完整 C++ SuperPlanner 与 Python 做端到端逐值对照。
固定文件位于 [tests/fixtures](../tests/fixtures)，重建入口位于 [tests/reference](../tests/reference)。

### 完整优化的数值限制

6 组普通固定输入的完整求解停止状态均与 C++ 相同。
Exp 最大位置差为 `7.43e-8 m`，Backup 为 `2.75e-3 m`。
真实 medium 输入的 Exp/Backup 最终目标相对差为 `0.496% / 0.692%`。
两者最大位置差为 `4.61 / 4.55 cm`。
这些结果说明目标和解析梯度接近，不说明非凸迭代终点完全相同。

新增显式热启动对照覆盖 Exp 两种位置参数化、Backup 非均匀时间和两次均匀时间继承。
每个阶段显式传入相同的 C++ 继承总时长，比较同一个优化问题。
一组均匀时间 Backup 的完整轨迹最大位置差达到 `0.677 m`。
该组最终目标相对差为 `4.15%`。
两侧切换时刻仅相差约 `1.43e-12 s`，不能用时间起点不同解释该差异。
第二次均匀时间继承调用的位置差为 `3.10 cm`，最终目标相对差为 `4.43%`。

扩展终点对照中，最大梯度分量尺度误差达到 `2.49e-4`。
最差输入的 MINCO 系统条件数约为 `5.44e9`。
同一公式的 Python float64 与 Numba 输出逐位一致。
提升到 longdouble 后，梯度明显移动，支持浮点消去放大的判断。
这些终点没有达到原严格梯度匹配容差，测试和报告保留该限制。
显式热启动重载未进入当前飞行主流程；其支持范围仍需要记录此差异。
逐项数值、源码哈希和条件诊断见 [数值证据汇总](data/super_validation_numerics.json)。

### 停顿的两类实际原因

开发阶段曾出现无碰撞长时间停止。
固定地图重放证明，当时存在路径，A* 的 Python 开销触发了原搜索超时。
后续完成等价搜索加速，保持路径、扩展顺序和超时检查位置。
这项修正不能解释或消除碰撞后的停顿。

最终 dense seed1 的停顿为 **26.58–90 s，共 63.42 s**。
该区间全部 25,369 个物理样本均处于几何接触。
实际平均速度为 `0.01436 m/s`，参考速度约为 `8.16e-15 m/s`。
参考保持 25.37 s 发布的备用终点。
`on_backup=true` 是最后发布命令的保留标志，不表示备用段仍在移动。

停顿期间 636 次 A* 均返回 `REACH_HORIZON`。
其中 454 次后续备用走廊生成失败。
几何错误为 `RISP seed intersects an occupied robot-radius ball`。
另有 182 次触发原 Exp 的 0.1 s 仿真时间分支。
原 FSM 因新命令未提交而持续保持 `GENERATE_TRAJ`。

该次首次碰撞发生于 16.935 s，正在执行备用制动。
参考高度为 1.69004 m，实际高度为 1.89825 m。
参考点距所撞固体约 0.300 m，实际机体接触其底面。
备用参考的最低垂直加速度为 `-13.59255 m/s²`。
16.80 s 起出现负推力请求，16.93 s 请求为 `-20.0553 N`，分配推力为 0。

### 跟踪与原执行策略的限制

medium seed0 的 94 次重规划接续连续，但终点附近仍失稳。

独立核验未发现四元数顺序、本体角速度或推力坐标错误。
四元数差分与记录角速度的均方根误差为 `2.09e-5 rad/s`。
