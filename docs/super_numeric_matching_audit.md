## 误差定位

1. 原 C++ 使用 `g++ -O0` 与 `g++ -O2` 分别编译。5 次显式热启动的终止变量、目标值、分段时间和多项式系数全部逐值相同。当前偏差不能归因为这两组编译选项。
2. 对第一次均匀时间 Backup 的迭代轨迹单独插桩。C++ 与 Python 的初始变量最大绝对差约 `1.03e-13`。第 10、15、35、45 次迭代的变量最大差分别约为 `1.10e-13`、`2.86e-9`、`1.25e-4`、`1.32`。早期线搜索步长一致；差异随迭代放大。
3. 在两侧最终变量上交叉调用原 C++ 与 Python 的**相同变量目标函数**。目标值与 MINCO 系数保持小尺度误差；最差终点梯度尺度误差为 `2.4945e-4`。该样本 MINCO 线性系统的 2-范数条件数约为 `5.44e9`。
4. 最差梯度分量在 C++、Python、80 位 `longdouble` 诊断中分别为 `1.06235892`、`1.06287338`、`1.06228156`，五点有限差分约为 `1.06228177`。高精度与有限差分更接近，说明原双精度算法在该病态点存在明显消去误差。不能把 C++ 双精度结果当作无限精度真值。
5. 实测调整时间幂的组合和梯度求和顺序后，首次均匀 Backup 位置差由 `0.677 m` 降至 `0.136 m`，第二次却由 `0.031 m` 增至 `0.318 m`。该变化不具备跨案例一致性，**已撤销**。
